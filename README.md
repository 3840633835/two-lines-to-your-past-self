A deterministic program that writes a two-line warning to your past self for make.fun's "Two Lines to Your Past Self" bounty: don't tattoo her name on your arm the day you turn eighteen — the ink fades but never leaves, and every new love reads the old one first.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt`: exactly two lines, newline-separated, no trailing newline, 136 bytes (inside the kit gate of 1–280 characters).
